Serverless HTML5 Game Architecture

How this game connects phones with zero backend server.

1. Peer-to-Peer WebRTC DataChannel

Uses native RTCPeerConnection + unreliable RTCDataChannel (ordered: false, maxRetransmits: 0) for ultra-low-latency gamepad input directly between phone and TV.

2. Multi-Touch Pointer Events

The virtual thumbstick and Boost/Pulse buttons use PointerEvents with touch-action: none and navigator.vibrate() for smooth console-like phone controls.

3. Static File Deployment

Drop this single .html file on GitHub Pages or Netlify Drop. Opening the URL launches straight into this full-screen game with no website chrome.
